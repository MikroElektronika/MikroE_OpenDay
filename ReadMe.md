# 🧠 NECTO Studio – Git Demo Repository

![MikroElektronika Logo](https://www.mikroe.com/img/designs/beta/logo_small.png)

This repository is designed to **demonstrate Git integration in [NECTO Studio](https://www.mikroe.com/necto)** — MikroElektronika’s next-generation IDE for embedded development.
It serves as a safe sandbox for exploring how version control works directly inside NECTO.

---

## 🎯 Purpose

This project showcases NECTO Studio’s built-in Git features, including:
- Cloning and initializing repositories
- Staging and committing changes
- Creating and merging branches
- Viewing commit history and diffs

It’s ideal for **hands-on training, workshops, or internal demonstrations**.

---

## 🚀 How to Use

1. **Open NECTO Studio → Version Control → Clone Repository**
2. Paste this repository URL and open the project
3. Make any small change (edit or create a file)
4. Use the **Version Control panel** to stage, commit, and push
5. Explore **branching, merging, and conflict resolution**

---

## ⚙️ Notes

- This repository is **non-production** and intended for educational/testing use
- Safe to experiment with — changes can always be reverted
- Recommended for anyone learning Git through NECTO Studio
